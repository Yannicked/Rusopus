Opus Decoder (Rust, no-FFI)

This workspace is the start of a pure-Rust Opus decoder (decoder-first port of `libopus`, no FFI).

Project plan: `OPUS_PORT_PLAN.md`.

## Dev commands

Run lint/tests:

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

Fetch official test vectors (downloads into `testdata/`):

```bash
cargo xtask fetch-vectors
cargo xtask gen-manifest
```

Conformance tests are present but currently `#[ignore]` until the decoder is implemented:

```bash
OPUS_TESTVECTORS_DIR="$(pwd)/testdata/opus_testvectors" \
  cargo test -p opus-decoder --test conformance_rfc -- --ignored
```

The conformance harness expects a `vectors.txt` manifest in the vectors directory
(generated by `cargo xtask gen-manifest`). See `testdata/vectors.example.txt`.
